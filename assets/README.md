# Assets de marca: LA FURY Tools & Jewelry

Origen: el arte del oso azul con gorra CUBA sobre las letras doradas "LA FURY", que nos dio el usuario.
Marca de las herramientas, la tienda y la joyería del juego. **El reloj se sigue llamando ZARUMEI.**

| Archivo | Uso |
|---|---|
| `lafury-logo.jpg` | 800×800, fondo negro original, optimizado para la web |
| `lafury-logo.png` / `.webp` | 1024 px de ancho, **fondo transparente** (recortado con un flood-fill desde los bordes negros, no hecho a mano) |
| `lafury-logo-512.webp`, `lafury-logo-256.png` | Versiones ligeras para la interfaz (encabezado de la caja de herramientas, tienda, títulos) |
| `lafury-badge-128.png` / `.webp` | Sello pequeño para iconos de herramientas |
| `lafury-decal-engrave-gold.png` / `-256.webp` | Calcomanía monocroma en tono oro, con estilo de **grabado**: mangos de destornillador, llave de fondo, soporte, aceitera |
| `lafury-decal-print-white.png` | Calcomanía monocroma clara, con estilo de **serigrafía**: carcasa y pantalla de arranque del timegrapher, cajas de joyería |

Cómo aplicarlas en 3D (Three.js o Unity): usar la calcomanía como textura en un plano o un *decal projector* sobre el mango o la carcasa, con mezcla alfa, y usar la luminancia como mapa de relieve o normal para que se vea grabado.

# Fuentes (SIL Open Font License 1.1)
Subconjuntos latinos (pyftsubset → woff2) de las familias de Google Fonts, todas con licencia OFL 1.1:
- **Cormorant Garamond** (Christian Thalmann) para los titulares serif
- **Cinzel** (Natanael Gama) para las versalitas de etiquetas
- **Jost** (indestructible type*) para el texto

`scripts/build.mjs` las incrusta en `fonts.css` como data URI.
